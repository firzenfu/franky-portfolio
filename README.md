# Franky Fu Portfolio

Personal portfolio for Franky Fu, a software developer in Edmonton building modern web experiences with AI-assisted workflows.

## Tech stack

- React 19
- TypeScript
- Vite
- Framer Motion

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm test
npm run build
```
